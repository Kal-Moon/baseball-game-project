# 야구 게임 비교 – 네이버 검색 추이와 카페·블로그 평가 (2026-11-16 조사)

국내외 야구 게임이 한국에서 얼마나 관심을 받는지(검색 추이), 게이머들이 무엇을 좋아하고 싫어하는지(카페·블로그 글)를 정리한 자료.

- 자료: NAVER API HUB(네이버 클라우드) **검색어 트렌드 API**, **검색 API(카페글·블로그)**. 2026-11-16 호출.
- 요금: 호출 전 요금 페이지 확인 (검색어 트렌드 0~30,000건 무료, 검색 API 0~775,000건 무료·하루 25,000건). 이 조사에 쓴 호출: 검색어 트렌드 9번(실패 2번 포함), 검색 API 50번.

## 1. 네이버 검색 추이 (2023-11 ~ 2026-10, 월별)

검색어 트렌드는 실제 검색 횟수가 아니라 **비율**(기간 안 최댓값 = 100)만 준다. 한 번에 5개까지만 비교되므로 모든 호출에 **컴투스프로야구**를 같이 넣고, 컴투스프로야구 합계 = 100으로 다시 계산했다.

| 순위 | 게임 | 최근 1년 (2025-11~2026-10) | 3년 전체 | 흐름 |
| --- | --- | --- | --- | --- |
| 1 | 컴투스프로야구 | **100** | 100 | 2025-04 최고, 이후 조금 내려와 유지 |
| 2 | MLB 더쇼 (콘솔, 미국) | 36.5 | 76.2 | 크게 줄어듦. 2026-07 반짝 |
| 3 | 마구마구 | 27.3 | 44.3 | 줄어듦 |
| 4 | 프로스피 (프로야구 스피리츠, 일본) | 14.9 | 13.3 | **늘어남**. 2026-03·07 최고 (2026판 한국어 지원) |
| 5 | MLB 9이닝스 | 8.4 | 28.2 | 크게 줄어듦 |

넣은 검색어 (게임마다 이 검색어들의 합):

- 컴투스프로야구: 컴투스프로야구, 컴프야, 컴투스 프로야구
- 컴투스프로야구V: 컴투스프로야구V, 컴프야V, 컴투스프로야구 V
- MLB 9이닝스: MLB9이닝스, MLB 9이닝스, 9이닝스
- 마구마구: 마구마구2020, 마구마구 게임, 넷마블 마구마구, 마구마구 쿠폰
- 이사만루: 프로야구 이사만루, 이사만루 게임, 이사만루 쿠폰, 이사만루2
- MLB 더쇼: MLB 더쇼, MLB The Show, 엠엘비 더쇼, 더쇼24·25·26 (붙여 쓰기·띄어 쓰기)
- 프로스피: 프로스피, 프로야구 스피리츠, 프로야구스피리츠
- 파워프로: 파워프로, 실황파워풀프로야구, 실황 파워풀 프로야구, 파워풀프로야구
- 프로야구 슬러거: 프로야구 슬러거, 프로야구슬러거, 슬러거 게임
- 나머지는 게임 이름의 붙여 쓰기·띄어 쓰기·영어 표기

주의할 점:

- **검색어가 다른 뜻과 겹치면 크게 부풀려진다.** 처음에는 "마구마구"(일상 말 "마구"), "이사만루"(중계의 "2사 만루"), "더쇼"(음악 방송), "슬러거"(일반 단어)를 넣었다가 고쳤다. 고치기 전후: 이사만루 45.5 → 2.0, 슬러거 127 → 0.1, 마구마구 59.5 → 44.3, MLB 더쇼 186 → 76 (3년 전체).
- 표기를 다 넣지 못한 게임은 낮게 나왔을 수 있다 (예: "컴프야V26"처럼 연도가 붙은 이름).
- **네이버(한국) 검색만** 본 것. 해외 인기(예: BASEBALL 9, MLB 9이닝스의 해외 매출)는 반영 안 됨.
- 검색이 많다 = 잘 만들었다는 뜻은 아님. 관심의 크기만 비교한 것.

## 2. 카페·블로그 평가

방법: 게임 5개(컴투스프로야구, MLB 더쇼, 마구마구, 프로스피, MLB 9이닝스) × 주제 5개(타격·투구·육성·단점·후기) × 카페·블로그, 각 상위 100개 = 50번 호출, 겹치는 글 빼고 3,996개. 쿠폰·이벤트·광고 글을 걸러 2,010개를 남기고, 의견이 담긴 글을 읽어 정리했다.

한계:

- 검색 API는 **제목과 짧은 요약(1~2문장)만** 준다. 본문 전체는 읽지 못했다 (블로그·카페 본문 페이지는 이 환경에서 막혀 있음).
- 카페 글은 날짜가 오지 않아 오래된 글(2010년대)이 섞여 있다. 블로그는 홍보·공략 글이 많다.
- 글 수를 세어 순위를 매긴 것이 아니라, 읽은 글에서 **자주 나온 이야기**를 모은 것. 아래 근거 글은 예시.

### 게임별로 자주 나온 이야기

**컴투스프로야구 (모바일, KBO 실명)**

- 좋은 점: 모바일 야구 중 **그래픽·타격감·홈런 연출**이 가장 좋다는 평이 많다. 직접 치고 던지는 손맛과 빠른 경기 템포.
- 아쉬운 점: **좋은 선수 카드 얻기가 어렵고 오래 걸린다**(골든글러브 뽑기, 무·소과금 가이드가 많음). 좋은 카드를 맞추면 계속 이긴다. 정면 타구가 너무 많고 상황 연출이 부족하다는 복귀 유저 글.
- 흥미로운 점: "투수 캐리는 되는데 타자 캐리는 어렵다"(투수진이 좋은 팀이 승률이 높다).
- 근거 예: [플레이 팁 v26](https://blog.naver.com/parkleeheart/224432962926), [v24 근황(퀄리티 칭찬)](https://blog.naver.com/wjdtjghks/223690471824), [복귀 유저 일주일 후기(공식 카페)](https://cafe.naver.com/com2usbaseball2015/1800559), [2026 리뷰](https://blog.naver.com/sylbanian11/224377010355)

**MLB 더쇼 (콘솔, MLB 실명)**

- 좋은 점: **그래픽·사실감·공 물리**가 가장 좋다는 평. **선수 키우기 모드(RTTS, 고교부터 한 선수를 키움)**가 가장 재밌었다는 글이 여럿. 난이도 조절(슬라이더)로 내 실력에 맞출 수 있음.
- 아쉬운 점: **타격이 너무 어렵다**("쳤다 하면 뜬공 병살", "안타 치기 자체가 어렵다"). **한국어 지원 없음**. 육성이 노가다. 해마다 크게 안 바뀐다("사골").
- 근거 예: [더쇼25 입문(육성 모드가 제일 재밌음)](https://cafe.naver.com/playps4/286187), [더쇼25 타격 어려움](https://cafe.naver.com/lionsball/3849071), [RTTS 노가다](https://cafe.naver.com/mlbtheshowpc/219), [더쇼26 후기 – 아쉬운 점이 더 많음](https://blog.naver.com/louis0826/224234752437)

**마구마구 (모바일·PC, KBO 실명, 2등신 캐릭터)**

- 좋은 점: 오래된 국민 야구 게임. 카드를 모아 덱(팀)을 꾸리는 재미. 조작에 익숙해지는 과정도 중요하다는 평.
- 아쉬운 점: **과금 부담**("선수 하나 올리는 데 너무 큰 금액"). **같은 구종만 던지는 투구("특구")**가 짜증 난다는 글이 반복됨 — 시스템이 그렇게 만든다는 장문 글도 있음. 렉·버그.
- 근거 예: [특구 장문 글](https://cafe.naver.com/abm/220984), [커브만 80% 던지는 상대](https://cafe.naver.com/abm/222647), [돈이 많이 드는 게임](https://cafe.naver.com/abm/263101), [시작 전 기본 플레이](https://cafe.naver.com/gpari/475)

**프로스피 (프로야구 스피리츠, 콘솔·PC, NPB 실명)**

- 좋은 점: **타격감·경쾌한 연출**이 가장 많이 칭찬받음 ("스피는 타격감, 더쇼는 야구장에 있는 느낌"). **투구 예상 지점이 실시간으로 보여서 더쇼보다 치기 쉽다.** 같은 투구라도 타격 반응에 따라 타구가 다양하게 나온다. 어시스트·난이도 설정이 세분화. 2026판은 시리즈 처음 한국어 지원·WBC(한국 선수) 모드 → 검색이 늘어난 이유로 보임.
- 아쉬운 점: 옛 시리즈는 일본어 압박, 타격이 어렵다는 글도 있음.
- 근거 예: [더쇼 유저의 프로스피 비교](https://cafe.naver.com/steamindiegame/21858365), [더쇼와 스피리츠 간단 비교](https://cafe.naver.com/prospirits/21224), [스피리츠6 vs 더쇼11 타구 다양성 테스트](https://cafe.naver.com/moopung/358504), [2026 한국어 지원 출시 후기](https://blog.naver.com/kimju0406/224354315663)

**MLB 9이닝스 (모바일, MLB 실명)**

- 좋은 점: MLB 라이선스로 실제 시즌을 보면서 하는 몰입감. 선수 육성·팀 꾸리기(단장 느낌).
- 아쉬운 점: **과금·뽑기 확률**, 상위 리그로 갈수록 구조적 한계로 그만둔다는 글. "가늘고 길게 해야 하는 게임".
- 근거 예: [뉴비 3달 후기(공식 카페)](https://cafe.naver.com/mlb9innings/326124), [9이닝스 26 아쉬움·환불 글](https://blog.naver.com/lunch1443/224298313078), [모바일 야구게임 순위 TOP5](https://blog.naver.com/greedady/223414262253)

### 게임 사이에서 겹치는 이야기 (우리 게임 기획에 참고)

| 자주 나온 이야기 | 어느 게임 | 우리 기획과 닿는 곳 |
| --- | --- | --- |
| 타격감·홈런 연출이 재미의 중심 | 컴프야, 프로스피, 더쇼 | 타격 조작, 필드 화면 연출 |
| 직접 타격이 너무 어려우면 지친다 / 공 예상 지점 표시가 있으면 쉬워진다 | 더쇼 ↔ 프로스피 | 타석 화면 정보, 선구 효과, 난이도 |
| 같은 타이밍에도 타구가 다양해야 재밌다 | 프로스피 | 타이밍 7단계·스윙 궁합 결과표 |
| 한 선수를 키우는 모드가 가장 재밌다 | 더쇼(RTTS) | 선수 육성 (성장 개념은 따로 다룰 때) |
| 같은 구종만 던지는 상대가 짜증 난다 | 마구마구 | 투수 구종 설계, 체력·구종 등급 |
| 좋은 카드만 맞추면 이기고, 그 카드를 얻기가 어렵다 / 과금 부담 | 컴프야, 마구마구, 9이닝스 | 성장·등급 체계, 재화 |
| 정면 타구가 너무 많다 | 컴프야 | 타구 방향 결과 (현실 통계 기반) |

이 표의 "닿는 곳"은 연결만 적은 것. 무엇을 바꿀지는 해당 주제를 다룰 때 KAL과 정한다.
