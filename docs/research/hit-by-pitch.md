## 2. 투수 제구(볼넷)와 관계가 있나 — MLB 2024·2025 직접 계산

| 항목 | 값 |
| --- | --- |
| 투수 사구율과 볼넷률의 상관 (한 시즌 400타석 이상, 각 135명) | 2024 **0.15**, 2025 **0.11** (거의 관계없음) |
| 투수 사구율 해마다 이어지는 정도 (두 해 모두 400타석 이상, 79명) | 0.53 (볼넷률은 0.58) |
| 타자 사구율 해마다 이어지는 정도 (두 해 모두 400타석 이상, 140명) | **0.64** |
| 투수 사구율 분포 (400타석 이상) | 2025: 하위 10% 0.40%, 가운데 0.85%, 상위 10% 1.72%, 최고 2.27% (세베리노) |
| 타자 사구율 분포 (400타석 이상) | 2025: 하위 10% 0.30%, 가운데 0.84%, 상위 10% 1.87%. 더빈 24개/506타석(4.7%), 아로자레나 27개/709타석 |

- 읽는 법: 볼넷을 많이 주는 투수라고 사구가 많지는 않음. 사구는 **투수마다 꾸준한 버릇**(몸쪽을 많이 던지는 투수)이고, **타자 쪽 버릇이 조금 더 꾸준함**(홈플레이트에 붙어 서는 타자).
- 예) 2024 로돌로: 볼넷률 7.5%(보통)인데 사구 18개/493타석(3.7%, 1위).
- 상관은 한 시즌 400타석 이상 투수만 본 값 (불펜 투수 대부분 빠짐).

## 3. 현실 규칙 (검색 요약)

- 사구는 대부분 고의가 아니고, 몸쪽을 노리다 몇 cm 빗나가서 나옴. 바깥쪽 공은 타자를 맞힐 수 없음 ([MLB 용어집](https://www.mlb.com/glossary/standard-stats/hit-by-pitch), 사이트가 막혀 원문 확인 못 함).
- 최근 MLB 사구 증가 이유로 타자가 홈플레이트 쪽으로 몸을 기울여 바깥쪽 공을 따라가는 것이 꼽힘 ([ESPN](https://www.espn.com/mlb/story/_/id/49464076), 원문 확인 못 함).
- KBO 헤드샷 규정 (2014년 도입, "배영섭 룰"): **직구가 머리에 맞거나 스치면 고의와 관계없이 투수 퇴장**, 변화구는 경고 ([OSEN](https://osen.co.kr/article/G1109755342)). 2026년 5월 19일 톨허스트 퇴장이 시즌 6번째 헤드샷 퇴장 ([aboda](https://aboda.kr/?p=27639), 블로그성 기사라 공식 집계는 확인 못 함).
- NPB는 1982년부터 위험구 퇴장 규정 (일본 독자 규정). 검색 요약에서 본 내용이고 어느 기사인지는 확인 못 함.
- KBO 2024~2025 NC 사구가 많은 이유로 감독은 ABS 도입 뒤 높은 공을 많이 던지게 된 것을 꼽음 ([노컷뉴스](https://www.nocutnews.co.kr/news/6358282), 원문 확인 못 함).
