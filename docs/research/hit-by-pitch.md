## 2. 사구와 제구(볼넷)의 관계

MLB 2025, 400타석 이상 투수 135명 (Savant 직접 계산).

| 볼넷 비율로 나눈 무리 | 볼넷/타석 | 사구/타석 |
| --- | --- | --- |
| 볼넷 적은 25% (제구 좋음) | 5.3% | 0.84% |
| 가운데 50% | 7.5% | 0.92% |
| 볼넷 많은 25% (제구 나쁨) | 10.0% | 0.98% |

- 투수별 볼넷 비율과 사구 비율의 **상관계수 0.11** (거의 관계없음). 볼넷은 제구 나쁜 무리가 약 2배인데 사구는 약 1.17배뿐.
- 사구가 가장 많은 투수 중에도 볼넷이 적은 투수가 있음. 예) 로돌로: 볼넷 4.8%(리그 상위)인데 사구 2.0%(최상위). 세일: 볼넷 6.3%, 사구 2.2%.
- 투수 사구 비율은 운이 커서 2년 넘게 봐야 안정됨 (볼넷은 약 반 시즌) ([Baseball Prospectus](https://www.baseballprospectus.com/?p=14293)).
- 정리: 사구는 "제구가 나빠서"보다 **몸쪽 승부와 구종**의 영향이 큼.

## 3. 구종별 사구

MLB 2025, 1,000구당 사구 (Savant 직접 계산, 전체 평균 2.72).

| 구종 | 전체 투구 중 비율 | 사구 중 비율 | 1,000구당 사구 |
| --- | --- | --- | --- |
| 싱커 (SI) | 15.5% | 27.4% | **4.80** |
| 스위퍼 (ST) | 7.7% | 10.3% | 3.61 |
| 커브 (CU) | 6.6% | 8.1% | 3.36 |
| 너클커브 (KC) | 1.9% | 1.8% | 2.62 |
| 커터 (FC) | 7.5% | 7.1% | 2.56 |
| 포심 (FF) | 31.9% | 25.8% | 2.20 |
| 스플리터 (FS) | 3.3% | 2.5% | 2.07 |
| 슬라이더 (SL) | 14.4% | 10.8% | 2.04 |
| 체인지업 (CH) | 10.3% | 4.1% | **1.09** |

- 싱커는 평균의 약 1.8배. 팔 쪽으로 휘며 가라앉아 같은 손 타자 몸쪽으로 파고드는 공. 스위퍼·커브도 많음 (크게 휘는 공이 반대 손 타자 쪽으로 빠짐).
- 체인지업은 평균의 약 0.4배 (주로 반대 손 타자 바깥쪽으로 던짐).
- 표본이 적은 구종(슬러브 SV, 포크볼 FO, 이퓨스 EP, 너클볼 KN)은 뺌.
- 투수 손·타자 손 조합별 사구는 확인하지 않음.

## 4. 사구로 인한 부상

- MLB 2011~2015년 사구 9,783개 중 부상 361건 → **사구 약 27개 중 1개(약 3.7%)가 부상**. 부상 한 건당 평균 결장 11.7일(MLB) ([Camp 외 2018, American Journal of Sports Medicine](https://vivo.weill.cornell.edu/display/pubid29768041), [FanGraphs 커뮤니티 글](https://community.fangraphs.com/mike-trout-and-the-hbp-risk/)). 논문 원문은 확인 못 함, 비율은 글의 숫자로 직접 계산.
- 부상 부위는 손·손가락 21.8%, 머리·얼굴 17.0%, 팔꿈치 15.7% (MLB + 마이너 합친 수치, 검색 요약).
- 한국 리그 사구 부상 비율은 확인 못 함.

## 5. 다른 야구 게임

- 파워프로 2026-2027: 실투가 사구가 되기 쉬워지는 특수능력 "死球集中", 몸쪽 공의 제구·구위가 오르는 "ケンカ投法"이 있음 (Game8 공략 검색 요약으로만 확인, 원문 확인 못 함, [Game8](https://game8.jp/pawapuro2026-2027/790789)).
- 컴프야·MLB The Show의 사구 처리 방식은 확인 못 함.

## 부록: 현실 규칙 (2026-10-08 조사, `claude/awesome-maxwell-pu3c6b`, 검색 요약)

- 사구는 대부분 고의가 아니고, 몸쪽을 노리다 몇 cm 빗나가서 나옴. 바깥쪽 공은 타자를 맞힐 수 없음 ([MLB 용어집](https://www.mlb.com/glossary/standard-stats/hit-by-pitch), 사이트가 막혀 원문 확인 못 함).
- 최근 MLB 사구 증가 이유로 타자가 홈플레이트 쪽으로 몸을 기울여 바깥쪽 공을 따라가는 것이 꼽힘 ([ESPN](https://www.espn.com/mlb/story/_/id/49464076), 원문 확인 못 함).
- KBO 헤드샷 규정 (2014년 도입, "배영섭 룰"): **직구가 머리에 맞거나 스치면 고의와 관계없이 투수 퇴장**, 변화구는 경고 ([OSEN](https://osen.co.kr/article/G1109755342)). 2026년 5월 19일 톨허스트 퇴장이 시즌 6번째 헤드샷 퇴장 ([aboda](https://aboda.kr/?p=27639), 블로그성 기사라 공식 집계는 확인 못 함).
- NPB는 1982년부터 위험구 퇴장 규정 (일본 독자 규정). 검색 요약에서 본 내용이고 어느 기사인지는 확인 못 함.
- KBO 2024~2025 NC 사구가 많은 이유로 감독은 ABS 도입 뒤 높은 공을 많이 던지게 된 것을 꼽음 ([노컷뉴스](https://www.nocutnews.co.kr/news/6358282), 원문 확인 못 함).
