# 공 단위 기록 (시뮬레이터 v2 중간 목표용)

2026-11-14 조사. 세부 설계 3단계 ③ "공 하나 계산 규칙"을 위한 자료.

## 1. MLB 2025 정규시즌 공 단위 비율

Baseball Savant 투수별 CSV를 직접 받아 합산 (존 = Statcast 구역 1~9, 존 밖 = 11~14, `hfZ`·`hfPR` 필터, 열 `pitches`·`swings`·`whiffs`).

| 항목 | 존 안 | 존 밖 |
| --- | --- | --- |
| 전체 투구 중 비율 | 50.6% | 49.4% |
| 스윙 비율 | 66.9% | 28.2% (체이스) |
| 스윙 중 헛스윙 | 17.3% | 44.7% |
| 스윙 중 파울 (파울팁 포함) | 42.0% | 34.1% |
| 스윙 중 인플레이 | 42.5% | 23.0% |
| 안 친 공 중 스트라이크 판정 | 87.6% | 4.5% |

- 전체 709,909구, 타석 182,926 → **타석당 투구 수 3.88**.
- 존 안 헛스윙 + 파울 + 인플레이 합이 101.8%로 조금 넘음. 헛스윙(`whiffs`)에 파울팁이 같이 들어가는 것으로 보임 (확인 못 함).
- 안 친 공의 판정은 MLB 사람 심판 기준 (존 안인데 볼 12.4%, 존 밖인데 스트라이크 4.5%).
- KBO의 공 단위 자료(스윙률·헛스윙률·타석당 투구 수)는 KBO 기록실에서 찾지 못함 (스탯티즈는 로그인 필요).
- 리그가 다름: KBO 삼진(19.4%)은 MLB보다 적어서 헛스윙 비율이 MLB보다 낮을 것으로 보임 (확인 못 함). MLB 수치는 **출발점**으로만 쓰고, 결과는 KBO 목표(5.4절)에 맞춤.

## 2. KBO 볼 판정 (ABS)

- KBO는 **2024시즌부터 1군에 ABS(자동 볼 판정)** 도입, 세계 최초. 카메라로 타자별 존을 정하고 기계가 판정 ([OSEN](https://osen.co.kr/article/G1112254569), [스포츠경향](https://sports.khan.co.kr/article/202404211518003)).
- 2024 존 높이는 타자 신장 비율 상단 56.35%, 하단 27.64% (검색 요약, 원문 확인 못 함).
- 목표 리그 평균(KBO 2024~2026)이 모두 ABS 시대라 "존 안 = 스트라이크"로 계산해도 기준이 맞음.
