## 1. KBO 리그 평균 (정규시즌, 각 720경기)

| 항목 | 2024 | 2025 | 시뮬레이터 v1 결과 (5.1절) |
| --- | --- | --- | --- |
| 타석 | 57,265 | 55,996 | |
| 타율 | .277 | .262 | .259 |
| 출루율 | .352 | .338 | .337 |
| 장타율 | .420 | .389 | .392 |
| 삼진 / 타석 | 18.9% | 19.7% | 18.6% |
| 볼넷 / 타석 | 9.2% | 9.1% | 9.3% |
| 사구 / 타석 | 1.37% | 1.44% | 1.2% (고정값) |
| 홈런 / 타석 | 2.51% | 2.13% | |
| 홈런 / 컨택 (삼진·볼넷·사구 뺀 타석) | 3.6% | 3.1% | 3.0% (기준값) |
| BABIP | .325 | .312 | .305 (기준값) |
| 2루타 / 안타 | 17.1% | 17.5% | 20% (기준값) |
| 3루타 / 안타 | 1.6% | 1.6% | 2% (기준값) |
| 팀당 경기 득점 | 5.38 | 4.73 | 4.3 |

- BABIP = (안타 − 홈런) / (타수 − 삼진 − 홈런 + 희생플라이)
- 홈런 / 컨택 = 홈런 / (타석 − 볼넷 − 사구 − 삼진)
- 2024는 타고 시즌(ABS 첫해), 2025는 타율 .262로 내려옴. 한 해 사이 차이가 커서 두 해를 섞지 않음.
- 2026 시즌은 10월 8일 기준 끝나지 않음 (약 707경기).
- 시뮬레이터 득점이 적은 이유는 확인 전. 도루·실책·진루타·폭투가 없어서일 가능성.
