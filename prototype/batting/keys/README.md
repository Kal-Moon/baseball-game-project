# 시험판 서명 키

`debug.keystore`는 **시험판 APK 전용 시험용 키**다 (KAL 결정, 2026-11-17).
같은 키로 서명해야 폰에 이미 깔린 앞 버전 위에 새 버전을 덮어 설치할 수 있어서 저장소에 고정했다.

- 별칭 `androiddebugkey`, 비밀번호 `android` (안드로이드 시험용 키의 관례값)
- 인증서 SHA-256: `87:00:C9:47:55:D5:B2:41:9D:FF:2B:D2:B6:1C:BC:1F:6F:7E:25:BB:C3:CA:DD:25:04:FC:03:E0:C7:4F:FC:BD`
- **정식 출시(플레이 스토어)에는 쓰지 않는다.** 출시용 키는 따로 만들고 저장소에 넣지 않는다.
